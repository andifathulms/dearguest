# Font licences — DearGuest brand (marketing site and couple's app)

Both families are licensed under the **SIL Open Font License 1.1**, which
permits commercial use, embedding and redistribution with the product. The
woff2 files are Google Fonts' own "latin" subsets, unmodified.

| File | Family | Source |
|---|---|---|
| `instrument-serif-400.woff2` | Instrument Serif, regular | github.com/google/fonts — `ofl/instrumentserif` |
| `instrument-serif-400-italic.woff2` | Instrument Serif, italic | same |
| `plus-jakarta-sans-var.woff2` | Plus Jakarta Sans, variable wght 400–700 | `ofl/plusjakartasans` (Tokotype, Jakarta) |

Neither family is used by a theme pack, so the shop never looks like one of its
products. Invitation pages never load these files: only `brand.css` declares them,
and only marketing and app pages import it.
