# Vowvella — logo & brand kit

Spelling: **Vowvella** · Tagline: **Untuk hari yang hanya satu** · Watermark: **Dibuat dengan Vowvella**

## logo/
All SVG, text outlined, flat colour, transparent background.

| File | Use |
|---|---|
| vowvella-lockup-* | Primary: mark + wordmark |
| vowvella-wordmark-* | Wordmark only |
| vowvella-stacked-* | Stacked with tagline |
| vowvella-mark-* | Symbol, 32 px and up |
| vowvella-mark-small-* | Symbol below 32 px (heavier hairline, no tails) |
| vowvella-mark-circle/square-* | Symbol in containers (Malam / Porcelain) |
| watermark-capsule-* | Free-plan footer; pick by theme tone (dark → malam, light → porcelain) |
| watermark-bare-* | Footer without capsule, only on calm areas |
| construction-clearspace.svg | Clear-space diagram |

Colour suffixes: `on-malam` (full colour for dark), `on-porcelain` (full colour for light), `gold`, `ink`, `white` (single colour — foil, emboss, print).

## Rules
- Clear space: x on all sides, x = height of the lowercase v.
- Minimum: lockup 96 px / 24 mm · wordmark 72 px / 18 mm · mark 16 px / 5 mm.
- Gold is a thin line or small detail, never a large fill.
- Don't stretch, recolour outside the palette, add shadows/gradients, or respell.
- Watermark: render at 26 px height (≈12 px text), centred, 16–24 px above the invitation bottom.
